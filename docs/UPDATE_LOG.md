### 💡 Советы по использованию

#### Для добавления Google Maps:

1. Получите API ключ: https://console.cloud.google.com/
2. Создайте iframe код карты
3. Вставьте в `contacts.html` вместо placeholder:

```html
<iframe 
    src="https://www.google.com/maps/embed?pb=YOUR_EMBED_CODE" 
    width="100%" 
    height="100%" 
    style="border:0;" 
    allowfullscreen="" 
    loading="lazy">
</iframe>
```

#### Для настройки формы контактов:

См. файл `DEPLOY.md` раздел "Backend интеграция"
