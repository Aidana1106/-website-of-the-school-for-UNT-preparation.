### 4. **Обновлённый JavaScript (script.js)**

Добавлена новая функция:
```javascript
function initTrialLesson() {
    const trialLessonBtn = document.getElementById('watchTrialLessonBtn');
    
    if (trialLessonBtn) {
        trialLessonBtn.addEventListener('click', () => {
            window.location.href = 'trial-lesson.html';
        });
    }
}
```

Функция инициализируется при загрузке страницы в `DOMContentLoaded`.

## 🚀 Как это работает?

1. **На главной странице** пользователь видит блок "Пробный урок" с кнопкой
2. **При клике на кнопку** — открывается `trial-lesson.html`
3. **На странице с видео** пользователь может:
   - Посмотреть встроенное YouTube-видео
   - Прочитать информацию о формате занятий
   - Перейти к программам или оставить заявку на консультацию
