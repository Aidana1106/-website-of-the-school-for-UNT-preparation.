# Инструкция по настройке Telegram бота для получения сообщений с сайта

## Шаг 1: Создание Telegram бота

1. Откройте Telegram и найдите бота **@BotFather**
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: `ENT-Bilim Support Bot`)
   - Введите username бота (должен заканчиваться на `bot`, например: `ent_bilim_support_bot`)
4. **Сохраните токен бота** - он будет выглядеть примерно так: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`

## Шаг 2: Создание группы для получения сообщений

### Вариант A: Группа (рекомендуется для команды менеджеров)

1. Создайте новую группу в Telegram
2. Добавьте вашего бота в группу (найдите его по username и добавьте)
3. Сделайте бота администратором группы (опционально, но рекомендуется)
4. Получите Chat ID группы:
   - Добавьте в группу бота **@userinfobot**
   - Отправьте любое сообщение в группу
   - Бот @userinfobot покажет Chat ID группы (будет отрицательным числом, например: `-1001234567890`)
   - **Сохраните этот Chat ID**

### Вариант B: Личный чат с ботом

1. Начните чат с вашим ботом
2. Отправьте любое сообщение боту
3. Получите Chat ID:
   - Откройте в браузере: `https://api.telegram.org/bot<123456789:ABCdefGHIjklMNOpqrsTUVwxyz>/getUpdates`
   - Замените `<ВАШ_ТОКЕН>` на токен вашего бота
   - Найдите `"chat":{"id":123456789}` - это и есть ваш Chat ID

## Шаг 3: Настройка переменных окружения

1. Создайте файл `.env` в корне проекта (если его еще нет)
2. Добавьте следующие строки:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота_здесь
TELEGRAM_CHAT_ID=ваш_chat_id_здесь
```

**Пример:**
```env
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_CHAT_ID=-1001234567890
```

## Шаг 4: Установка зависимостей

Выполните в терминале:
```bash
npm install
```

Это установит библиотеку `axios`, необходимую для отправки запросов в Telegram API.

## Шаг 5: Перезапуск сервера

После настройки переменных окружения перезапустите сервер:
```bash
npm start
```

## Как это работает

1. Пользователь заполняет форму на сайте (контакты, главная страница)
2. Данные отправляются на сервер (`/api/telegram/send-message`)
3. Сервер форматирует сообщение и отправляет его в вашу Telegram группу/чат
4. Менеджеры видят заявку в Telegram и могут ответить пользователю

## Ответ пользователям

### Способ 1: Через inline кнопки (в разработке)

В сообщении будут кнопки "Ответить" и "Обработано" для быстрой обработки заявок.

### Способ 2: Вручную

1. Скопируйте контакт пользователя из сообщения
2. Свяжитесь с пользователем по указанному email или телефону
3. Нажмите кнопку "Обработано" в сообщении (когда будет реализовано)

### Способ 3: Автоматический ответ через бота (будущая функция)

Можно настроить бота для автоматической отправки ответов пользователям. Для этого потребуется:
- Сохранять chat_id пользователей при их регистрации
- Настроить webhook для получения обновлений от Telegram
- Реализовать логику ответа на сообщения

## Тестирование

1. Заполните форму на сайте
2. Проверьте, что сообщение пришло в Telegram группу/чат
3. Убедитесь, что все данные отображаются корректно

## Безопасность

⚠️ **ВАЖНО:**
- Никогда не публикуйте токен бота в открытом доступе
- Не коммитьте файл `.env` в Git
- Добавьте `.env` в `.gitignore`

## Дополнительные настройки бота (опционально)

Вы можете настроить бота через @BotFather:
- `/setdescription` - описание бота
- `/setabouttext` - информация о боте
- `/setuserpic` - установить фото бота
- `/setcommands` - установить команды бота

## Поддержка

Если возникли проблемы:
1. Проверьте, что токен бота правильный
2. Проверьте, что Chat ID правильный
3. Убедитесь, что бот добавлен в группу (если используете группу)
4. Проверьте логи сервера на наличие ошибок
