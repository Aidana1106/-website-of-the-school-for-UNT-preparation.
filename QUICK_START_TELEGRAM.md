## 🔍 Шаг 3: Получите Chat ID

### Вариант A: Через скрипт (рекомендуется)

1. **Отправьте сообщение боту:**
   - Откройте Telegram
   - Найдите бота: **@ent_bilim_support_bot**
   - Отправьте любое сообщение (например: `/start` или "Привет")

2. **Запустите скрипт:**
   ```bash
   node get-chat-id.js
   ```

3. **Скопируйте Chat ID** из вывода скрипта

4. **Добавьте Chat ID в .env файл:**
   ```env
   TELEGRAM_CHAT_ID=ваш_chat_id_здесь
   ```

### Вариант B: Создайте группу для менеджеров

1. **Создайте группу в Telegram:**
   - Создайте новую группу
   - Добавьте бота **@ent_bilim_support_bot** в группу
   - Отправьте любое сообщение в группу

2. **Получите Chat ID группы:**
   - Добавьте в группу бота **@userinfobot**
   - Отправьте сообщение в группу
   - @userinfobot покажет Chat ID группы (отрицательное число, например: `-1001234567890`)

3. **Добавьте Chat ID в .env файл**

### Вариант C: Через API напрямую

1. Отправьте сообщение боту или в группу
2. Откройте в браузере:
   ```
   https://api.telegram.org/bot8268785420:AAHulwutqa9iwQRSPw5zohsT3IUcJmOZKi0/getUpdates
   ```
3. Найдите `"chat":{"id":123456789}` - это ваш Chat ID
4. Добавьте в .env файл
