## ✏️ Что нужно изменить?

### 1️⃣ Добавьте изображения

Найдите в HTML комментарии:
```html
<!-- [PHOTO_1_HERO] — hero banner photo background -->
<!-- [PHOTO_2_PROGRAMS_1] — image for program 1 -->
```

Замените placeholder'ы на реальные фото.

### 2️⃣ Настройте формы

В файле `js/script.js` найдите функцию `handleFormSubmit` и добавьте API:

```javascript
fetch('/api/submit-form', {
    method: 'POST',
    body: JSON.stringify(formData)
})
```

### 3️⃣ Измените контакты

В `index.html` найдите footer и измените:

## 🌐 Как переключить язык?

Нажмите кнопки **RU** или **KZ** в шапке сайта.

Чтобы изменить переводы, откройте `js/translations.js`:

```javascript
const translations = {
    ru: {
        hero_title: "Ваш новый заголовок"
    },
    kz: {
        hero_title: "Сіздің жаңа тақырыбыңыз"
    }
};
```

## 📱 Как протестировать на телефоне?

### Вариант 1: В браузере
1. Откройте DevTools (F12)
2. Нажмите Toggle Device Toolbar (Ctrl+Shift+M)
3. Выберите iPhone или Android

### Вариант 2: На реальном телефоне
1. Запустите локальный сервер
2. Найдите IP вашего компьютера: `ipconfig` (Windows) или `ifconfig` (Mac/Linux)
3. Откройте на телефоне: `http://192.168.X.X:8000`

## 🔧 Частые вопросы

### ❓ Формы не работают?
**Ответ:** Формы пока демо-версия. Нужно подключить backend (см. `DEPLOY.md`)

### ❓ Слайдер не скользит?
**Ответ:** Проверьте подключение Swiper.js в `index.html` (строка с CDN)

### ❓ Анимации не работают?
**Ответ:** Проверьте подключение AOS.js в `index.html`

### ❓ Как добавить Google Analytics?
**Ответ:** См. раздел "Аналитика" в `DEPLOY.md`

### ❓ Можно ли использовать для коммерции?
**Ответ:** Да! Лицензия MIT позволяет любое использование.
