## 📱 Мобильное приложение

### Варианты разработки:

#### 1. PWA (Progressive Web App)
**Преимущества:**
- Работает на всех платформах
- Установка из браузера
- Оффлайн-режим
- Push-уведомления

**Реализация:**
```javascript
// manifest.json
{
  "name": "ENT-Bilim",
  "short_name": "ENT-Bilim",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#6366f1",
  "theme_color": "#6366f1",
  "icons": [
    {
      "src": "/icon-192.png",
      "sizes": "192x192",
      "type": "image/png"
    }
  ]
}

// service-worker.js
self.addEventListener('install', (e) => {
  e.waitUntil(
    caches.open('ent-bilim-v1').then((cache) => {
      return cache.addAll([
        '/',
        '/css/style.css',
        '/js/script.js'
      ]);
    })
  );
});
```

## 🔐 Безопасность

### Что реализовать:

1. **HTTPS** — обязательно
2. **CSP Headers** — защита от XSS
3. **Rate Limiting** — защита от спама
4. **CAPTCHA** — защита форм (reCAPTCHA v3)
5. **Шифрование данных** — для личной информации
6. **2FA** — двухфакторная аутентификация

**Пример CSP:**
```html
<meta http-equiv="Content-Security-Policy" 
      content="default-src 'self'; script-src 'self' 'unsafe-inline' https://cdn.jsdelivr.net;">
```
