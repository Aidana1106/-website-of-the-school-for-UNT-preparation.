## Типы изменений

- **Добавлено** (Added) - для новых функций
- **Изменено** (Changed) - для изменений существующей функциональности
- **Устарело** (Deprecated) - для функций, которые скоро будут удалены
- **Удалено** (Removed) - для удаленных функций
- **Исправлено** (Fixed) - для исправления багов
- **Безопасность** (Security) - для уязвимостей безопасности

## Семантическое версионирование

Проект использует [SemVer](https://semver.org/):

**MAJOR.MINOR.PATCH**

- **MAJOR** - несовместимые изменения API
- **MINOR** - новая функциональность (обратно совместимая)
- **PATCH** - исправления багов (обратно совместимые)

Пример: `1.2.3`
- 1 = Major версия
- 2 = Minor версия
- 3 = Patch версия
